# Reference

Every entry of the package, with its main names, checked against each `src/<module>/index.ts`. Rows starting with "types" list type-only exports. For full signatures, read the doc comments in the source.

## `wallhammer-web` (root)

Re-exports `base`, `platform`, `core`, `gen-core`, `gen-mesh`, `gen-tex`, `gpu`, `camera`, `env`, `world` and `tools`. Not `render`, `sim`, `sim/destruction`, `runtime`, `gen-arch`, `gen-ground`, `gen-vegetation`, nor the Node-only `marks-store`.
